## [3.0.0] - 2026-02-20

### First Release

- **PyInstaller Packaging** - GUI-based one-click packaging with custom icon, resources, and output directory
- **Environment Cloning** - Three modes: brute-force clone, clean clone, and standard deps download
- **Dependency Analysis** - Auto-analyze `.py` imports, support `requirements.txt` and `pyproject.toml`
- **Portable Python Bundling** - Online/offline modes with project file bundling
- **Dark/Light Theme** - Toggle between dark and light themes
- **Drag & Drop** - Drop `.py` files and folders directly into the window (requires tkinterdnd2)
- **Multi-Python Detection** - Auto-detect installed Python versions for environment cloning
